#  Data Analyst Telegram Bot

A Telegram-based **Data Analyst Bot** that allows users to ask data-related questions and get solutions directly through Telegram.

## What It Does

Users can send a question or data-analysis request to the Telegram bot. The bot processes the request and provides a **clear solution, analysis, or answer**.

### Example

**User:**

> What is the average sales value?

**Bot:**

> The average sales value is calculated and returned with the result.

##  Features

*  Ask questions through Telegram
*  Get automated analysis and solutions
*  AI-powered responses
*  Simple and interactive Telegram interface
*  Designed to assist with data-related tasks

## Tech Stack

* Python
* Groq API
* Telegram Bot API
* Data Analysis / AI
* Pandas

## Purpose

The goal of this project is to make **data analysis simple and accessible through a Telegram chatbot**, allowing users to ask questions and receive solutions without needing a separate data-analysis application.
